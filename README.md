# Iris-svm-classification
irisデータセットを用いたSVMによる多クラス分類。 標準化・統計分析・学習曲線・混同行列・決定境界の可視化まで一連の機械学習パイプラインを実装/Multi-class classification using SVM on the Iris dataset. Implements a full machine learning pipeline including statistical analysis, learning curves, confusion matrix, and decision boundary visualization.
